CHALO – INTEGRATED PROJECT

Open this folder in VS Code and run index.html with Live Server.

Pages: index.html (homepage), login.html, register.html, gift-booking.html.

CSS organization:
- css/styleshome.css: original homepage styling
- css/stylescommon.css: shared login/auth design elements
- css/styleslogin.css: login/auth page styling

JavaScript:
- js/main.js: homepage interactions
- js/login.js: login form interactions/validation

Assets:
- assets/chalo-logo.png: your supplied logo image (replace it with your preferred logo if needed)
- assets/gift-box.png: existing gift image from your original project

The original homepage is preserved as index.html. The login page is a separate login.html.
Login and registration currently provide frontend interactions/validation only; real account authentication requires a backend.


BACKEND: See README_BACKEND_SETUP.txt for XAMPP, MySQL import, registration and login setup.
